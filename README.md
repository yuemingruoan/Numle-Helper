# Numle Helper - 数字猜谜游戏助手

这是一个用于解决类 Wordle 数字猜谜游戏（通常称为 Numle）的 C++ 命令行工具。它可以帮助您根据已有的线索计算出最佳猜测，或者验证某个数字组合。

## 功能

*   **检查模式 (`check`)**: 当您知道谜底时，可以用来快速验证某个猜测的结果（包含几个数字、位置正确几个数字）。
*   **求解模式 (`solve`)**: 核心功能，一个强大的解谜助手。
    *   支持不同位数的数字。
    *   可以根据您提供的线索（例如，`12345` 这个猜测有 `2` 个数字包含在谜底中，`1` 个数字位置正确）来排除不可能的组合。
    *   能够自动计算并推荐当前局面下的**最佳猜测**。
*    **自动遍历模式**: 通过自动遍历测试性能

## 如何使用

需事先安装 python3、uv
``` sh
uv sync
uv run main.py
```
